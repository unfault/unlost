# Ground Truth Design

## Overview

To measure the **Utility** of various extraction strategies, we need a "Golden Set" or "Ground Truth" (GT) against which we can compare. The Ground Truth represents the maximum possible information we can extract from a conversation turn with human-level comprehension.

## The Sprint Set (Ground Truth Dataset)

We have selected **50 turns** from the following sessions for manual labeling:
- `ses_3a2ae1953ffekU6ydgG3lCxNat` (unlost development)
- `ses_4867cc9e5ffe8Thtw9frHujUeZ` (unfault development)

## Labeling Schema

For each turn in the Sprint Set, we will manually define:

### 1. IntentCapsule (The "Perfect" Capsule)
- **Category**: Precise classification (e.g., `bugfix`, `feature`, `refactor`, `chore`, `question`).
- **Intent**: Concise summary of what the user wanted (e.g., "Add parallel execution to replay command").
- **Decision**: What the assistant proposed or what was agreed upon (e.g., "Use tokio::task::spawn with a semaphore for concurrency control").
- **Rationale**: The "Why" (e.g., "To speed up replay without hitting API rate limits").
- **Symbols**: Complete list of files, functions, and identifiers mentioned or touched.
- **Failure Mode**: Correct identification of any friction (e.g., `retry_spiral`, `drift`, or `none`).

### 2. Pivotal Status
- **is_pivotal**: Boolean. Is this a "pivotal" turn that significantly changes the project state or reveals a failure?
- **pivotal_reason**: Brief note on why (e.g., "Architectural decision on concurrency model").

### 3. Search Queries
- **target_queries**: 1-3 natural language queries that *should* find this turn (e.g., "How did we implement parallel replay?").

## Evaluation Methodology

### A. Semantic Search (Recall@K)
We will run the `target_queries` against the embeddings generated by each strategy.
- **Success**: The GT turn appears in the top $K$ (usually $K=5$).

### B. Field Accuracy
For structured fields, we compare strategy output ($S$) to Ground Truth ($GT$):
- **Symbols**: F1-score of the symbols set.
- **Category**: Exact match or semantic equivalence.
- **Failure Mode**: Precision/Recall of detecting non-`none` modes.

### C. Narrative Quality (LLM-as-a-Judge)
We use a "Teacher" LLM (e.g., GPT-4o) provided with:
1. The full conversation transcript for context.
2. The Ground Truth capsule.
3. The Strategy's extracted capsule.

**Prompt**: "How well does the strategy capsule capture the essence of the Ground Truth? Rate 1-5."
